# 银龄盾｜对话核验助手

面向老年人消费与金融场景的反诈风险提示原型。用户粘贴短信或多轮对话后，程序按轮识别部分风险信号与行为阶段，展示触发原句、行动建议，并从项目知识卡中检索可核验资料。

## 运行方法

1. 安装 Python 3.10 或更新版本。
2. 在本项目文件夹打开终端，运行：`python -m pip install -r requirements.txt`
3. 运行：`streamlit run app.py`
4. 浏览器打开后，将对话粘贴到输入框并点“开始核验”。

Windows 用户也可以双击 `run_streamlit.bat`。如仅想查看离线静态演示页，可双击 `run_app.bat` 或 `index.html`；静态页与 Streamlit 网页是两个独立入口。

## 文件和数据

- `app.py`：Streamlit 交互网页。
- `agent.py`：风险规则、阶段汇总、行动建议和知识卡检索。
- `data/dialogues.csv`：对话级样例及人工汇总标签。
- `data/turns.csv`：逐轮对话及标注信息。
- `data/knowledge.csv`：知识卡及来源信息。
- `data/DATA_NOTES.md`：数据构成、字段口径和局限。
- `index.html`：可离线打开的独立静态页面。
- `requirements.txt`：Streamlit 运行依赖。

## 项目边界

当前是本地规则原型，不是训练好的机器学习模型，不连接大语言模型或短信平台。输出只是风险提示，不构成诈骗定性；未发现信号也不表示绝对安全。家属协同只生成可检查、可复制的核实卡，不会自动发送。

程序不把用户输入写入数据文件。演示请使用模拟对话，不要输入真实验证码、密码、身份证号、银行卡号或其他个人信息。当前数据尚未划分锁定测试集，因此不报告准确率。公开仓库前，请确认数据不含个人信息且团队有权公开。
